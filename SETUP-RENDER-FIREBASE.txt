================================================================================
  SOLUCIONAR: "Firebase Admin no configurado en el servidor" (Render)
================================================================================

Ese error = la variable FIREBASE_SERVICE_ACCOUNT_JSON NO está en Render,
está vacía, o el JSON está mal pegado.

PASO 1 — Descargar clave (solo una vez)
--------------------------------------
1. https://console.firebase.google.com  → proyecto torneo-sc2
2. Engranaje "Configuración del proyecto"
3. Pestaña "Cuentas de servicio"
4. Botón "Generar nueva clave privada" → descarga torneo-sc2-xxxxx.json

PASO 2A — Secret File en Render (MÁS FÁCIL)
-------------------------------------------
1. dashboard.render.com → torneo-sc2 → Environment
2. Secret Files → Add Secret File
3. Filename: firebase-service-account.json
4. Contents: pega TODO el .json de Firebase (Ctrl+A del archivo)
5. Save → redeploy

PASO 2B — Variable de entorno (alternativa)
--------------------------------------------
1. Environment → Add Environment Variable
2. Key: FIREBASE_SERVICE_ACCOUNT_JSON
3. Value: todo el JSON en una línea (minifica en jsonformatter.org si falla)

   IMPORTANTE al cambiar Gmail: NO borres Firebase ni APP_PUBLIC_URL

4. Save → redeploy

PASO 3 — Otras variables obligatorias para invitar
---------------------------------------------------
Añade también (misma pantalla Environment):

   APP_PUBLIC_URL = https://torneo-sc2.onrender.com/admin.html

   (Para correo, ver SETUP-EMAIL.txt: SMTP_HOST, SMTP_USER, SMTP_PASS, etc.)

PASO 4 — Esperar el deploy (2–5 min)
------------------------------------
Render → Events / Logs hasta ver "Live" o deploy verde.

PASO 5 — Comprobar (en el navegador)
------------------------------------
Abre:

   https://torneo-sc2.onrender.com/api/health

Debe verse algo así:

   "firebaseAdmin": true
   "firebaseEnvSet": true
   "firebaseJsonValid": true
   "firebaseHint": null
   "emailConfigured": true    ← también necesitas SMTP para el correo

Si ves:
   firebaseEnvSet: false  → no guardaste la variable o nombre mal escrito
   firebaseJsonValid: false → JSON roto; mira "firebaseHint"

PASO 6 — Invitar de nuevo
-------------------------
https://torneo-sc2.onrender.com/admin.html
Inicia sesión → Enviar invitación
