================================================================================
  GMAIL API — Invitaciones desde Render (recomendado)
================================================================================

Render bloquea SMTP. Gmail API usa HTTPS y funciona bien.

Necesitas 4 variables en Render:
  GMAIL_CLIENT_ID
  GMAIL_CLIENT_SECRET
  GMAIL_REFRESH_TOKEN
  GMAIL_USER          (correo Gmail que envía, ej. tu@gmail.com)

Opcional:
  EMAIL_FROM = Torneo StarCraft <tu@gmail.com>
  APP_PUBLIC_URL = https://torneo-sc2.onrender.com/admin.html

--------------------------------------------------------------------------------
PASO 1 — Google Cloud (mismo proyecto que Firebase torneo-sc2)
--------------------------------------------------------------------------------
1. https://console.cloud.google.com  → selecciona proyecto torneo-sc2
2. Menú ☰ → APIs y servicios → Biblioteca
3. Busca "Gmail API" → Habilitar

--------------------------------------------------------------------------------
PASO 2 — Pantalla de consentimiento OAuth
--------------------------------------------------------------------------------
1. APIs y servicios → Pantalla de consentimiento de OAuth
2. Tipo: Externo → Crear
3. Nombre de la app: Torneo SC2
4. Correo de asistencia: tu correo
5. Usuarios de prueba → Añadir tu Gmail (el que enviará correos)
6. Guardar

--------------------------------------------------------------------------------
PASO 3 — Credenciales OAuth
--------------------------------------------------------------------------------
1. APIs y servicios → Credenciales → Crear credenciales
2. ID de cliente de OAuth → Tipo: Aplicación web
3. Nombre: torneo-sc2-gmail
4. URIs de redirección autorizados → Añadir AMBAS:
     http://localhost:3333/oauth2callback
     https://developers.google.com/oauthplayground
5. Crear → copia:
     - ID de cliente        → GMAIL_CLIENT_ID
     - Secreto del cliente  → GMAIL_CLIENT_SECRET

--------------------------------------------------------------------------------
PASO 4A — Refresh token con OAuth Playground (recomendado)
--------------------------------------------------------------------------------
https://developers.google.com/oauthplayground/

1. Engranaje (OAuth 2.0 configuration) arriba a la derecha:
   - Marca "Use your own OAuth credentials"
   - OAuth Client ID = tu GMAIL_CLIENT_ID
   - OAuth Client secret = tu GMAIL_CLIENT_SECRET
   - Close

2. Step 1 — En "Input your own scopes" pega:
     https://mail.google.com/

   Clic "Authorize APIs" → elige el Gmail que ENVIARÁ invitaciones → Permitir

3. Step 2 — Clic "Exchange authorization code for tokens"

4. Copia el "Refresh token" (empieza con 1//0...) → Render:
     GMAIL_REFRESH_TOKEN=...

(Opcional: el script local npm run gmail:token hace lo mismo sin Playground.)

--------------------------------------------------------------------------------
PASO 4B — Refresh token con script local (alternativa)
--------------------------------------------------------------------------------
  $env:GMAIL_CLIENT_ID="PEGA_EL_CLIENT_ID"
  $env:GMAIL_CLIENT_SECRET="PEGA_EL_CLIENT_SECRET"
  npm run gmail:token

--------------------------------------------------------------------------------
PASO 5 — Variables en Render
--------------------------------------------------------------------------------
Environment → Add:

  GMAIL_CLIENT_ID       = (del paso 3)
  GMAIL_CLIENT_SECRET   = (del paso 3)
  GMAIL_REFRESH_TOKEN   = (del paso 4)
  GMAIL_USER            = tu@gmail.com   (el mismo Gmail del paso 4)
  GMAIL_REDIRECT_URI    = https://developers.google.com/oauthplayground
  (opcional) EMAIL_FROM = Torneo SC2 <tu@gmail.com>
  APP_PUBLIC_URL        = https://torneo-sc2.onrender.com/admin.html
  FIREBASE_SERVICE_ACCOUNT_JSON = (NO la borres al cambiar Gmail)

IMPORTANTE: En Render BORRA estas variables si existen (si no, /api/health dirá smtp y no enviará):
  SMTP_HOST, SMTP_PORT, SMTP_USER, SMTP_PASS, RESEND_API_KEY

Save → espera deploy.

--------------------------------------------------------------------------------
PASO 6 — Comprobar
--------------------------------------------------------------------------------
https://torneo-sc2.onrender.com/api/health

  "emailMode": "gmail-api"
  "emailConfigured": true

Invita desde admin.html → el correo sale desde tu Gmail (revisa spam).

--------------------------------------------------------------------------------
Errores frecuentes
--------------------------------------------------------------------------------
- "Access blocked" → añade tu correo en Usuarios de prueba (paso 2)
- "invalid_grant" → vuelve a ejecutar gmail-get-token.mjs con prompt consent
- "insufficient permission" → scope debe ser https://mail.google.com/
- redirect_uri_mismatch → URI exacta http://localhost:3333/oauth2callback
